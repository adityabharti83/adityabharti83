## 🧠 About Me

I like taking data that's raw, messy, and half-broken — and turning it into something a stakeholder could actually make a decision from.

My path so far: **Clustor Computing** (Data Analytics Intern) → **thinkbridge** (Data Engineer Apprentice) → building my own end-to-end portfolio project from scratch to prove I can own a pipeline start to finish, not just polish a notebook.

I care less about "does the chart look nice" and more about **"is the data underneath it actually correct."** That's the itch that led me to build validation and testing into my own projects instead of skipping straight to the dashboard.

**Real PMPML GTFS data → BigQuery → Power BI**
